# Plan M1: Font Flip + Emoji Purge — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retire IBM Plex from the Android app — Inter for UI text, JetBrains Mono for data/mono styles — and remove every user-visible emoji, per the approved spec `docs/superpowers/specs/2026-07-11-modern-look-fixes-design.md` (Plan M1 section).

**Architecture:** All 50 screen files consume typography through the central `SmithType` object, whose 18 styles point at `FontFamily` objects declared in `ConsoleTheme.kt`. Flipping ~10 `fontFamily =` lines in `SmithType.kt` re-skins the app. `ConsoleTheme`'s own TextStyles have ZERO consumers (verified 2026-07-11, internal and external) and are deleted along with the Plex declarations and font files so Plex cannot regress — there are no CI grep gates in this repo.

**Tech Stack:** Kotlin / Jetpack Compose, Gradle 8.2, plain-JVM JUnit4 unit tests (they already construct `SmithType`/`ConsoleTheme` directly — see `SmithTabularTest.kt`).
