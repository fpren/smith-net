| Field | Value |

---

## 1. Problem

Pricing-config.json defines three founder bonus pools (Solo: 1000, Advanced: 100, Enterprise: 10) that must be enforced **server-authoritatively and atomically** — never double-allocate, never lie about scarcity. F2.2's resolver currently returns hardcoded counts; this PRD replaces that with real DB-backed accounting.

## 2. Goal

After this PRD:
- `founder_seats` table tracks every seat (claimed, held, available)
- `founderSeatService.reserve(bonusId, profileId)` atomically holds a seat for 10 minutes
- `claim(reservationId)` finalizes after checkout
- `release(reservationId)` returns to pool on abandon / hold expiry
- Live count via WS push `founder_seats_changed` event
- Concurrency-safe under load (1000 parallel claims → exactly 1000 succeed)

## 3. Non-goals

- The CTA UI that triggers reservations (F4.1 LockedFeatureOverlay)
- Stripe checkout integration (F3.1 — claim is called *after* payment success)
- Admin UI for managing seats (out of scope v1)

## 4. Design

### 4.1 Migration M3 — `create_founder_seats_table.sql`

```sql
-- 007_create_founder_seats_table.sql
BEGIN;

CREATE TABLE IF NOT EXISTS founder_seats (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  bonus_id TEXT NOT NULL CHECK (bonus_id IN (
    'solo_founder_pricing_lock',
    'advanced_lifetime_template_library',
    'enterprise_founder_annual_pricing'
  )),
  seat_number INTEGER NOT NULL,
  total_seats INTEGER NOT NULL,
  status TEXT NOT NULL DEFAULT 'available'
    CHECK (status IN ('available', 'held', 'claimed', 'released')),
  held_by TEXT REFERENCES profiles(id),
  held_until TIMESTAMPTZ,
  claimed_by TEXT REFERENCES profiles(id),
  claimed_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (bonus_id, seat_number)
);

CREATE INDEX IF NOT EXISTS idx_founder_seats_status ON founder_seats(bonus_id, status);
CREATE INDEX IF NOT EXISTS idx_founder_seats_held_until ON founder_seats(held_until)
  WHERE status = 'held';

-- Pre-mint seats once
INSERT INTO founder_seats (bonus_id, seat_number, total_seats)
SELECT 'solo_founder_pricing_lock', g, 1000 FROM generate_series(1, 1000) g
ON CONFLICT DO NOTHING;

INSERT INTO founder_seats (bonus_id, seat_number, total_seats)
SELECT 'advanced_lifetime_template_library', g, 100 FROM generate_series(1, 100) g
ON CONFLICT DO NOTHING;

INSERT INTO founder_seats (bonus_id, seat_number, total_seats)
SELECT 'enterprise_founder_annual_pricing', g, 10 FROM generate_series(1, 10) g
ON CONFLICT DO NOTHING;

-- Add FK back to subscriptions.founder_seat_id (was added without FK in F2.1)
ALTER TABLE subscriptions
  ADD CONSTRAINT fk_subscriptions_founder_seat
  FOREIGN KEY (founder_seat_id) REFERENCES founder_seats(id);

COMMIT;
```

### 4.2 Service

```typescript
// backend/src/services/founderSeatService.ts
import { pg } from '../db';

export type FounderBonusId =
  | 'solo_founder_pricing_lock'
  | 'advanced_lifetime_template_library'
  | 'enterprise_founder_annual_pricing';

export interface Reservation { id: string; bonusId: FounderBonusId; expiresAt: Date; }

const HOLD_MINUTES = 10;

export async function reserve(bonusId: FounderBonusId, profileId: string): Promise<Reservation | null> {
  // Atomic: SELECT one available seat, UPDATE to 'held' in same txn using FOR UPDATE SKIP LOCKED
  const client = await pg.connect();
  try {
    await client.query('BEGIN');
    const { rows } = await client.query(
      `SELECT id FROM founder_seats
        WHERE bonus_id = $1 AND status = 'available'
        ORDER BY seat_number ASC
        LIMIT 1
        FOR UPDATE SKIP LOCKED`,
      [bonusId]
    );
    if (rows.length === 0) {
      await client.query('COMMIT');
      return null; // exhausted
    }
    const seatId = rows[0].id;
    const expiresAt = new Date(Date.now() + HOLD_MINUTES * 60 * 1000);
    await client.query(
      `UPDATE founder_seats SET status='held', held_by=$2, held_until=$3 WHERE id=$1`,
      [seatId, profileId, expiresAt]
    );
    await client.query('COMMIT');
    broadcastSeatChange(bonusId);
    return { id: seatId, bonusId, expiresAt };
  } catch (e) {
    await client.query('ROLLBACK');
    throw e;
  } finally {
    client.release();
  }
}

export async function claim(reservationId: string, profileId: string): Promise<boolean> {
  const { rowCount } = await pg.query(
    `UPDATE founder_seats
       SET status='claimed', claimed_by=$2, claimed_at=NOW(), held_until=NULL
     WHERE id=$1 AND status='held' AND held_by=$2`,
    [reservationId, profileId]
  );
  if (rowCount === 1) {
    const { rows } = await pg.query(`SELECT bonus_id FROM founder_seats WHERE id=$1`, [reservationId]);
    broadcastSeatChange(rows[0].bonus_id);
    return true;
  }
  return false;
}

export async function release(reservationId: string): Promise<void> {
  const { rows } = await pg.query(
    `UPDATE founder_seats SET status='available', held_by=NULL, held_until=NULL
       WHERE id=$1 AND status='held'
     RETURNING bonus_id`,
    [reservationId]
  );
  if (rows.length) broadcastSeatChange(rows[0].bonus_id);
}

export async function getCount(bonusId: FounderBonusId) {
  const { rows } = await pg.query(
    `SELECT
       COUNT(*) FILTER (WHERE status='available') AS remaining,
       COUNT(*) AS total
     FROM founder_seats WHERE bonus_id=$1`,
    [bonusId]
  );
  return { remaining: Number(rows[0].remaining), total: Number(rows[0].total) };
}

export async function getAllCounts() {
  return {
    solo: await getCount('solo_founder_pricing_lock'),
    advanced: await getCount('advanced_lifetime_template_library'),
    enterprise: await getCount('enterprise_founder_annual_pricing'),
  };
}

function broadcastSeatChange(bonusId: FounderBonusId) {
  // wsHandler emits 'founder_seats_changed' to all connected clients
  wsHandler.broadcast({ type: 'founder_seats_changed', payload: { bonusId } });
}
```

### 4.3 Hold-expiry cron

```typescript
// backend/src/jobs/releaseExpiredHolds.ts
// Run every 60s
export async function releaseExpiredHolds() {
  const { rows } = await pg.query(
    `UPDATE founder_seats
       SET status='available', held_by=NULL, held_until=NULL
     WHERE status='held' AND held_until < NOW()
     RETURNING bonus_id`
  );
  const bonusIds = new Set(rows.map(r => r.bonus_id));
  bonusIds.forEach(broadcastSeatChange);
}
```

### 4.4 Endpoint

```typescript
// GET /api/founder-seats/:bonusId
apiRouter.get('/founder-seats/:bonusId', async (req, res) => {
  const { bonusId } = req.params;
  const validIds = ['solo_founder_pricing_lock', 'advanced_lifetime_template_library', 'enterprise_founder_annual_pricing'];
  if (!validIds.includes(bonusId)) return res.status(400).json({ error: 'invalid bonus_id' });
  res.json(await getCount(bonusId as FounderBonusId));
});
```

| AC-1 | M3 migration runs idempotently and pre-mints 1110 seats total | Migration test |

## 6. BDD scenarios

```gherkin
Feature: Founder seats reserved atomically

Scenario: Reserve a Solo founder seat
  Given 1000 available solo_founder_pricing_lock seats
  When a profile reserves one
  Then 999 seats remain available
  And 1 seat is held for that profile
  And held_until is approximately NOW + 10 minutes

Scenario: 1001st simultaneous reservation fails
  Given 1000 available solo_founder_pricing_lock seats
  When 1001 parallel reservation requests arrive
  Then exactly 1000 succeed
  And 1 returns null (exhausted)

Scenario: Held seat auto-releases after 10 minutes
  Given a seat held for profile P with held_until in the past
  When releaseExpiredHolds cron runs
  Then the seat status is "available"
  And held_by is NULL

Scenario: Claim finalizes the hold
  Given a held seat by profile P
  When claim(seatId, P) is called
  Then status becomes "claimed"
  And claimed_at is set
  And held_until is NULL

Scenario: Claim by wrong profile fails
  Given a seat held by profile P
  When claim(seatId, OtherProfile) is called
  Then it returns false
  And the seat remains held by P

Scenario: WS broadcast on every state change
  When any of reserve/claim/release fires
  Then a WS event "founder_seats_changed" with payload.bonusId is broadcast to all clients
```

## 8. Risk

| Risk | Mitigation |
|---|---|
| `FOR UPDATE SKIP LOCKED` not supported on older Postgres | Hetzner uses recent Postgres; minimum 12+ |
| Cron misses run window | Failures are non-blocking; held seats stay held until next cron |
| WS broadcast storms | Batch by bonus_id within a 100ms window |
| Counter drift if cron stops | Manual recount: `SELECT bonus_id, COUNT(*) FROM founder_seats GROUP BY bonus_id, status` |
