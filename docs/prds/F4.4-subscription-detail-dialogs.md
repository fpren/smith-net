# F4.4 — SubscriptionDetailScreen + Cancel/Delete dialogs

| Field | Value |
|---|---|
| Pitch | 4 — Tier-gate UI |
| Cycle | 3 |
| Appetite | 4 days |
| Owner | Android |
| Dependencies | F2.2, F3.1/F3.2 (cancel/reactivate endpoints), F7.1 (downgrade) |

---

## 1. Problem

Self-service subscription management. Without it, users can't see what they're paying for or cancel — that's a trust failure even if billing works.

## 2. Goal

Full screen + 2 confirmation dialogs per `WIREFRAME-SPEC §6` covering all 11 N8 states (`STATE-SPEC §N8`).

## 3. Design

### 3.1 SubscriptionDetailScreen

```kotlin
// android/.../ui/subscription/SubscriptionDetailScreen.kt
@Composable
fun SubscriptionDetailScreen(
    onBack: () -> Unit,
    onUpgradeTo: (Tier) -> Unit,
    onSwitchAnnual: () -> Unit,
    onUpdateCard: () -> Unit,
    onExportData: () -> Unit,
    onCancel: () -> Unit,
    onReactivate: () -> Unit,
    onDelete: () -> Unit,
) {
    val state by SubscriptionRepository.flow.collectAsState()
    val sub = state ?: return Loading()

    Column(Modifier.fillMaxSize().background(ConsoleTheme.background)) {
        StandardHeader(title = "SUBSCRIPTION", onBack = onBack)
        ConsoleSeparator()

        Column(Modifier.fillMaxSize().verticalScroll(rememberScrollState()).padding(16.dp)) {
            CurrentTierSection(sub)
            ConsoleSeparator()
            if (sub.tier != Tier.OPEN) {
                NextBillSection(sub)
                ConsoleSeparator()
                if (sub.founderPriceLocked) {
                    FounderPricingSection(sub)
                    ConsoleSeparator()
                }
            }
            ChangeTierSection(sub, onUpgradeTo, onSwitchAnnual)
            ConsoleSeparator()
            if (sub.tier != Tier.OPEN) {
                PaymentMethodSection(sub, onUpdateCard)
                ConsoleSeparator()
            }
            DataSection(sub, onExportData, onCancel, onReactivate, onDelete)
        }
    }
}

@Composable
private fun CurrentTierSection(sub: SubscriptionState) {
    Column {
        Text("CURRENT TIER", style = ConsoleTheme.captionBold)
        Spacer(Modifier.height(10.dp))
        when (sub) {
            is SubscriptionState.Open -> {
                Text("Smith Net Open", style = ConsoleTheme.bodyBold)
                Text("\$0 / month", style = ConsoleTheme.body)
            }
            is SubscriptionState.PaidActive -> {
                Text("${displayName(sub.tier)}${if (sub.cancelAtPeriodEnd) " (canceling ${formatDate(sub.currentPeriodEnd)})" else ""}",
                    style = ConsoleTheme.bodyBold)
                Text("\$${sub.dollarsPerPeriod} / ${sub.cadenceLabel} (billed ${sub.cadenceLabel})", style = ConsoleTheme.body)
            }
            is SubscriptionState.TrialActive -> {
                Text("${displayName(sub.tier)} (TRIAL — ${sub.daysLeft} DAYS LEFT)",
                    style = ConsoleTheme.bodyBold, color = ConsoleTheme.primary)
            }
        }
    }
}

@Composable
private fun DataSection(sub: SubscriptionState, onExport: () -> Unit, onCancel: () -> Unit,
                        onReactivate: () -> Unit, onDelete: () -> Unit) {
    Column {
        Text("DATA", style = ConsoleTheme.captionBold)
        Spacer(Modifier.height(10.dp))
        ChevronRow("Export my data", onClick = onExport)
        if (sub is SubscriptionState.PaidActive && !sub.cancelAtPeriodEnd) {
            ChevronRow("Cancel subscription", onClick = onCancel)
        } else if (sub is SubscriptionState.PaidActive && sub.cancelAtPeriodEnd) {
            ChevronRow("Reactivate subscription", onClick = onReactivate)
        }
        ChevronRow("Delete account", onClick = onDelete)
    }
}
```

### 3.2 CancelSubscriptionDialog (custom Composable, NOT Material AlertDialog)

```kotlin
@Composable
fun CancelSubscriptionDialog(
    tier: Tier,
    periodEndDate: Date,
    inFlight: Boolean,
    onKeep: () -> Unit,
    onCancel: () -> Unit,
) {
    Box(Modifier.fillMaxSize().background(Color.Black.copy(alpha = 0.4f))) {
        Column(
            Modifier
                .align(Alignment.Center)
                .widthIn(max = 320.dp)
                .background(ConsoleTheme.surface)
                .border(1.dp, ConsoleTheme.outline, RoundedCornerShape(6.dp))
                .padding(14.dp)
        ) {
            Text("CANCEL SUBSCRIPTION?", style = ConsoleTheme.captionBold)
            Spacer(Modifier.height(12.dp))
            Text("Your ${displayName(tier)} features stay until end of current period (${formatDate(periodEndDate)}).",
                style = ConsoleTheme.body)
            Spacer(Modifier.height(8.dp))
            Text("After that you'll be on Open. Your data stays.", style = ConsoleTheme.body)
            Spacer(Modifier.height(18.dp))

            Row(horizontalArrangement = Arrangement.SpaceBetween, modifier = Modifier.fillMaxWidth()) {
                PrimaryCta("KEEP ${displayName(tier).uppercase()}") { onKeep() }
                SecondaryCta(
                    label = if (inFlight) "CANCELING..." else "Cancel anyway",
                    enabled = !inFlight,
                    onClick = { onCancel() }
                )
            }
        }
    }
    // Outside-tap does NOT dismiss (intentional per MICRO-INTERACTIONS §6.4)
    // Back button → equivalent to KEEP (handled by parent route)
}
```

### 3.3 DeleteAccountDialog (similar pattern, with red text)

```kotlin
@Composable
fun DeleteAccountDialog(inFlight: Boolean, onKeep: () -> Unit, onDelete: () -> Unit) {
    Box(Modifier.fillMaxSize().background(Color.Black.copy(alpha = 0.4f))) {
        Column(
            Modifier.align(Alignment.Center).widthIn(max = 320.dp)
                .background(ConsoleTheme.surface)
                .border(1.dp, ConsoleTheme.outline, RoundedCornerShape(6.dp))
                .padding(14.dp)
        ) {
            Text("DELETE ACCOUNT?", style = ConsoleTheme.captionBold)
            Spacer(Modifier.height(12.dp))
            Text("Your account will be deleted in 30 days. After that, this is irreversible.",
                style = ConsoleTheme.body)
            Spacer(Modifier.height(8.dp))
            Text("Sealed Ledger entries cannot be deleted (compliance).", style = ConsoleTheme.caption,
                color = ConsoleTheme.textMuted)
            Spacer(Modifier.height(18.dp))
            Row(horizontalArrangement = Arrangement.SpaceBetween, modifier = Modifier.fillMaxWidth()) {
                PrimaryCta("KEEP ACCOUNT") { onKeep() }
                Text(
                    if (inFlight) "DELETING..." else "Delete anyway",
                    style = ConsoleTheme.caption,
                    color = ConsoleTheme.error,  // ONLY place red is allowed
                    modifier = Modifier.clickable(enabled = !inFlight) { onDelete() }
                )
            }
        }
    }
}
```

## 4. Server endpoints (to wire)

- `POST /api/me/cancel` — already in F3.1 (Stripe) + F3.2 (Play); stub here, parity check
- `POST /api/me/reactivate` — symmetric undo of cancel
- `POST /api/me/data/export` — emails ZIP link (separate non-blocking job)
- `POST /api/me/account/delete` — soft-delete + 30d cooling-off (separate PRD; here just trigger UI)

## 5. Acceptance criteria

| AC | Description |
|---|---|
| AC-1 | All 11 N8 states render correctly per `STATE-SPEC §N8` |
| AC-2 | Cancel row is normal-styled (not red) |
| AC-3 | Tap Cancel opens custom CancelSubscriptionDialog (not Material AlertDialog) |
| AC-4 | KEEP closes dialog, no API call |
| AC-5 | Cancel anyway → POST /api/me/cancel → on success dialog closes + Toast |
| AC-6 | Reactivate row appears when status='canceled' and period not yet ended |
| AC-7 | Delete account opens DeleteAccountDialog with red "Delete anyway" text |
| AC-8 | Outside-tap does NOT dismiss dialogs |
| AC-9 | Back button dismisses dialog (= KEEP) |
| AC-10 | Annual switch row only shown if currently monthly |
| AC-11 | Founder pricing section only shown if `founderPriceLocked` |
| AC-12 | Payment failure state shows red text in row |

## 6. BDD scenarios

```gherkin
Scenario: User cancels Solo subscription
  Given a paid Solo user
  When they tap Cancel subscription
  Then CancelSubscriptionDialog appears
  And it shows "Your Solo features stay until end of current period"
  When they tap Cancel anyway
  Then POST /api/me/cancel is called
  And on success the dialog closes and Toast shows "Solo cancels [date]"
  And N8 re-renders with "Reactivate subscription" row

Scenario: User decides to keep
  Given the cancel dialog is open
  When they tap "KEEP SOLO"
  Then dialog closes with no API call
  And telemetry does not fire

Scenario: Outside-tap doesn't dismiss
  Given any confirmation dialog is open
  When user taps the dimmed background
  Then the dialog stays open
  And no action is taken
```
