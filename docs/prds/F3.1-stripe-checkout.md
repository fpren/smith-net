# F3.1 — Stripe Checkout + webhook handlers

| Field | Value |
|---|---|
| Pitch | 3 — Stripe + Play Billing |
| Cycle | 2 |
| Appetite | 6 days |
| Owner | backend |
| Dependencies | F1.4 (email verified before purchase), F2.1, F2.2 |
| Closes blocker | B2 (web/desktop part), S9 (Critical) |

---

## 1. Problem

No web/desktop billing exists. Cannot collect payment from Solo / Advanced users on the desktop portal. Stripe webhook signatures must be verified to prevent forged subscription updates.

## 2. Goal

After this PRD: a contractor on the web portal (or Android via web view fallback) can:
- Tap "Upgrade to Solo" → Stripe Checkout session
- Pay with card → server creates subscriptions row → tier upgrades
- Webhook events from Stripe atomically update subscription state
- Idempotency: re-delivered webhooks don't double-process

## 3. Non-goals

- Play Billing integration (F3.2)
- Subscription reconciler cron (F3.3)
- The Android in-app upgrade UI (F4.x — uses web checkout via custom tab/web view for v1)
- Refund automation (manual via Stripe dashboard for Enterprise)
- Apple Pay / Google Pay (Stripe handles natively)

## 4. Design

### 4.1 Stripe products + prices

| Product | Stripe price IDs |

### 4.2 Checkout session endpoint

```typescript
// POST /api/me/upgrade
import Stripe from 'stripe';
const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!, { apiVersion: '2024-06-20' });
import { reserve as reserveFounderSeat } from './services/founderSeatService';

const UpgradeBody = z.object({
  targetTier: z.enum(['solo', 'advanced', 'enterprise']),
  cadence: z.enum(['monthly', 'annual']),
  founderBonus: z.boolean().optional(),
}).strict();

apiRouter.post('/me/upgrade', requireVerifiedEmail, validateBody(UpgradeBody),
  async (req: AuthenticatedRequest, res) => {
    const { targetTier, cadence, founderBonus } = req.body;
    const profileId = req.user!.id;

    // Pick price ID
    const priceId = pickStripePriceId(targetTier, cadence, founderBonus);

    // Optionally reserve founder seat (10 min hold)
    let founderSeatId: string | undefined;
    if (founderBonus) {
      const reservation = await reserveFounderSeat(founderBonusFor(targetTier), profileId);
      if (!reservation) {
        // seats exhausted — fall back to standard pricing
        // re-pick standard priceId
      } else {
        founderSeatId = reservation.id;
      }
    }

    // Create checkout session
    const session = await stripe.checkout.sessions.create({
      mode: 'subscription',
      payment_method_types: ['card'],
      line_items: [{ price: priceId, quantity: 1 }],
      customer_email: req.user!.email,
      client_reference_id: profileId,
      metadata: { profileId, targetTier, cadence, founderSeatId: founderSeatId || '' },
      subscription_data: {
        metadata: { profileId, targetTier, founderSeatId: founderSeatId || '' },
      },
      success_url: `${PORTAL_URL}/subscription/success?session_id={CHECKOUT_SESSION_ID}`,
      cancel_url: `${PORTAL_URL}/subscription/canceled`,
    });

    res.json({ checkout_url: session.url, session_id: session.id });
  }
);
```

### 4.3 Webhook handler

```typescript
// POST /webhooks/stripe — UNAUTHENTICATED, signature-verified
import express from 'express';
const STRIPE_WEBHOOK_SECRET = process.env.STRIPE_WEBHOOK_SECRET!;

if (!STRIPE_WEBHOOK_SECRET) throw new Error('[FATAL] STRIPE_WEBHOOK_SECRET required');

app.post('/webhooks/stripe',
  express.raw({ type: 'application/json' }),  // need raw body for signature verification
  async (req, res) => {
    const sig = req.headers['stripe-signature'];
    let event;
    try {
      event = stripe.webhooks.constructEvent(req.body, sig as string, STRIPE_WEBHOOK_SECRET);
    } catch (err: any) {
      console.warn('[stripe-webhook] signature verification failed:', err.message);
      return res.status(400).send(`Webhook Error: ${err.message}`);
    }

    // Idempotency: check provider_webhook_events
    const { rows: existing } = await pg.query(
      `SELECT id FROM provider_webhook_events WHERE id = $1`, [event.id]
    );
    if (existing.length > 0) {
      return res.status(200).json({ received: true, deduped: true });
    }
    await pg.query(
      `INSERT INTO provider_webhook_events (id, provider, event_type, payload)
       VALUES ($1, 'stripe', $2, $3::jsonb)`,
      [event.id, event.type, JSON.stringify(event)]
    );

    // Process
    try {
      switch (event.type) {
        case 'checkout.session.completed':
          await handleCheckoutCompleted(event.data.object as Stripe.Checkout.Session);
          break;
        case 'customer.subscription.updated':
          await handleSubscriptionUpdated(event.data.object as Stripe.Subscription);
          break;
        case 'customer.subscription.deleted':
          await handleSubscriptionDeleted(event.data.object as Stripe.Subscription);
          break;
        case 'invoice.paid':
          await handleInvoicePaid(event.data.object as Stripe.Invoice);
          break;
        case 'invoice.payment_failed':
          await handleInvoiceFailed(event.data.object as Stripe.Invoice);
          break;
      }
      await pg.query(
        `UPDATE provider_webhook_events SET processed_at = NOW() WHERE id = $1`,
        [event.id]
      );
    } catch (e) {
      console.error('[stripe-webhook] handler error', event.type, e);
      return res.status(500).send('handler error');
    }
    res.status(200).json({ received: true });
  }
);
```

### 4.4 Handlers

```typescript
async function handleCheckoutCompleted(session: Stripe.Checkout.Session) {
  const profileId = session.metadata?.profileId;
  const targetTier = session.metadata?.targetTier as Tier;
  const founderSeatId = session.metadata?.founderSeatId || null;

  if (!profileId || !targetTier) return;

  const subscriptionId = typeof session.subscription === 'string' ? session.subscription : session.subscription?.id;
  if (!subscriptionId) return;

  // Fetch subscription details
  const sub = await stripe.subscriptions.retrieve(subscriptionId);

  // Insert subscriptions row
  await pg.query(`
    INSERT INTO subscriptions
      (profile_id, tier, cadence, provider, provider_subscription_id, provider_customer_id,
       status, current_period_start, current_period_end, founder_price_locked, founder_seat_id,
       cents_per_period, trial_started_at, trial_ends_at)
    VALUES ($1,$2,$3,'stripe',$4,$5,$6,
            to_timestamp($7), to_timestamp($8), $9, $10, $11, $12, $13)
    ON CONFLICT (provider, provider_subscription_id) DO UPDATE
      SET status = EXCLUDED.status, updated_at = NOW()
  `, [
    profileId, targetTier, sub.items.data[0].price.recurring?.interval === 'year' ? 'annual' : 'monthly',
    sub.id, sub.customer, sub.status,
    sub.current_period_start, sub.current_period_end,
    !!founderSeatId, founderSeatId,
    sub.items.data[0].price.unit_amount,
    sub.trial_start ? new Date(sub.trial_start * 1000) : null,
    sub.trial_end ? new Date(sub.trial_end * 1000) : null,
  ]);

  // Update profile.tier
  await pg.query(`UPDATE profiles SET tier=$2, tier_expires_at=NULL WHERE id=$1`, [profileId, targetTier]);

  // Claim founder seat (finalize the hold)
  if (founderSeatId) {
    await claimFounderSeat(founderSeatId, profileId);
    await pg.query(`UPDATE profiles SET founder_pricing_locked_at=NOW() WHERE id=$1`, [profileId]);
  }

  // Telemetry
  await emit('tier_upgrade.paid_converted', profileId, targetTier);
}

async function handleSubscriptionUpdated(sub: Stripe.Subscription) {
  await pg.query(`
    UPDATE subscriptions
       SET status = $2, current_period_end = to_timestamp($3),
           cancel_at_period_end = $4, updated_at = NOW()
     WHERE provider = 'stripe' AND provider_subscription_id = $1
  `, [sub.id, sub.status, sub.current_period_end, sub.cancel_at_period_end]);
}

async function handleSubscriptionDeleted(sub: Stripe.Subscription) {
  await pg.query(`UPDATE subscriptions SET status='expired' WHERE provider_subscription_id=$1`, [sub.id]);
  // Tier downgrade handled by F7.1 cron
}

async function handleInvoiceFailed(invoice: Stripe.Invoice) {
  await pg.query(`
    UPDATE subscriptions SET status='past_due' WHERE provider_subscription_id=$1
  `, [invoice.subscription]);
  // Email notification handled separately
}

async function handleInvoicePaid(invoice: Stripe.Invoice) {
  // Subscription extension implicit; provider sends customer.subscription.updated separately
}
```

## 6. BDD scenarios

```gherkin
Feature: Stripe checkout + webhook handling

Scenario: User completes Solo upgrade
  Given a verified Open user
  When POST /api/me/upgrade with {targetTier:"solo", cadence:"monthly", founderBonus:true}
  Then a founder seat is reserved
  And a Stripe Checkout session is created with the right price
  And the response includes the checkout URL
  When the user completes Stripe Checkout
  And Stripe delivers checkout.session.completed webhook with valid signature
  Then a subscriptions row is created with status="active" or "trialing"
  And profile.tier becomes "solo"
  And the founder seat is claimed
  And telemetry "tier_upgrade.paid_converted" fires

Scenario: Forged webhook rejected
  When a webhook with invalid Stripe-Signature header arrives
  Then the response is 400
  And no DB changes occur

Scenario: Duplicate webhook deduped
  Given event "evt_xxx" was already processed
  When the same event arrives again
  Then the response is 200 with deduped:true
  And no duplicate row is inserted

Scenario: Invoice payment fails
  Given an active Solo subscription
  When invoice.payment_failed webhook arrives
  Then subscriptions.status becomes "past_due"
  And the user receives email notification (separate)
```

## 7. Edge cases

| Case | Behavior |
|---|---|
| User abandons checkout | Founder seat hold expires after 10 min (F5.1 cron); subscription never created |
| Founder seats exhausted between reserve attempt and checkout | Standard price used; UI flags pre-checkout (per F4.3 N7 state 7.6) |
| Webhook delayed > 1h | Subscriptions reconciler (F3.3) catches up |
| Customer disputes charge → Stripe refunds | Manual: founder reverses via Stripe; subscription marks canceled via webhook |
| Currency mismatch | All prices USD v1; Stripe enforces |

|---|---|
