## 1. Problem

`profiles` has no `tier` column. There's no `subscriptions` table. Tier-aware features (caps, gates, entitlements) have nothing to read from.

## 2. Goal

After this PRD: schema can represent every tier state described in `OFFER_ARCHITECTURE.md` + `pricing-config.json`. Tier resolver service (F2.2) and billing service (F3.1) can build on this substrate.

## 3. Non-goals

- The actual TierResolver service (F2.2)
- founder_seats table (F5.1 — separate concurrency story)
- gate_hit_events table (F5.2 — separate telemetry story)
- Data migration from legacy `plans` to `intents` (M6 — deferred per Step-10 deferred-pitches)

## 4. Design

### 4.1 Migration M1 — `add_tier_columns_to_profiles.sql`

```sql
-- 005_add_tier_columns_to_profiles.sql
BEGIN;

ALTER TABLE profiles
  ADD COLUMN IF NOT EXISTS tier TEXT NOT NULL DEFAULT 'open'
    CHECK (tier IN ('open', 'solo', 'advanced', 'enterprise')),
  ADD COLUMN IF NOT EXISTS tier_expires_at TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS trial_started_at TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS trial_tier TEXT
    CHECK (trial_tier IN ('solo', 'advanced', 'enterprise')),
  ADD COLUMN IF NOT EXISTS trial_cc_captured BOOLEAN DEFAULT false,
  ADD COLUMN IF NOT EXISTS founder_pricing_locked_at TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS pdf_sends_this_month INTEGER NOT NULL DEFAULT 0,
  ADD COLUMN IF NOT EXISTS pdf_sends_month_key TEXT NOT NULL DEFAULT to_char(NOW(), 'YYYY-MM');

CREATE INDEX IF NOT EXISTS idx_profiles_tier ON profiles(tier);
CREATE INDEX IF NOT EXISTS idx_profiles_tier_expires ON profiles(tier_expires_at) WHERE tier_expires_at IS NOT NULL;

COMMIT;
```

**Backfill:** all existing users default to `tier='open'` (per CHECK + DEFAULT). Manual: founder is set to `tier='admin'` post-migration via `UPDATE profiles SET tier='enterprise' WHERE id='admin-uuid'` (or whatever admin tier should be).

### 4.2 Migration M2 — `create_subscriptions_table.sql`

```sql
-- 006_create_subscriptions_table.sql
BEGIN;

CREATE TABLE IF NOT EXISTS subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  profile_id TEXT NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  tier TEXT NOT NULL CHECK (tier IN ('solo', 'advanced', 'enterprise')),
  cadence TEXT NOT NULL CHECK (cadence IN ('monthly', 'annual')),
  provider TEXT NOT NULL CHECK (provider IN ('stripe', 'play_billing', 'manual')),
  provider_subscription_id TEXT NOT NULL,
  provider_customer_id TEXT,
  status TEXT NOT NULL CHECK (status IN ('trialing', 'active', 'past_due', 'canceled', 'expired')),
  current_period_start TIMESTAMPTZ,
  current_period_end TIMESTAMPTZ,
  cancel_at_period_end BOOLEAN DEFAULT false,
  founder_price_locked BOOLEAN DEFAULT false,
  founder_seat_id UUID,  -- FK added later in F5.1 (cycle 2) when founder_seats table exists
  cents_per_period INTEGER NOT NULL,  -- 299 / 999 / 5000 / 50000 (annual)
  trial_started_at TIMESTAMPTZ,
  trial_ends_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (provider, provider_subscription_id)
);

CREATE INDEX IF NOT EXISTS idx_subscriptions_profile ON subscriptions(profile_id);
CREATE INDEX IF NOT EXISTS idx_subscriptions_status ON subscriptions(status);
CREATE INDEX IF NOT EXISTS idx_subscriptions_period_end ON subscriptions(current_period_end)
  WHERE status IN ('trialing', 'active');

-- Idempotency table for webhook events
CREATE TABLE IF NOT EXISTS provider_webhook_events (
  id TEXT PRIMARY KEY,        -- provider's event id (Stripe event.id, Play orderId, etc.)
  provider TEXT NOT NULL,
  event_type TEXT NOT NULL,
  payload JSONB NOT NULL,
  received_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  processed_at TIMESTAMPTZ
);

CREATE INDEX IF NOT EXISTS idx_provider_webhook_events_processed ON provider_webhook_events(processed_at);

COMMIT;
```

### 4.3 Reversibility

```sql
-- 005_add_tier_columns_to_profiles.down.sql
BEGIN;
DROP INDEX IF EXISTS idx_profiles_tier_expires;
DROP INDEX IF EXISTS idx_profiles_tier;
ALTER TABLE profiles
  DROP COLUMN IF EXISTS pdf_sends_month_key,
  DROP COLUMN IF EXISTS pdf_sends_this_month,
  DROP COLUMN IF EXISTS founder_pricing_locked_at,
  DROP COLUMN IF EXISTS trial_cc_captured,
  DROP COLUMN IF EXISTS trial_tier,
  DROP COLUMN IF EXISTS trial_started_at,
  DROP COLUMN IF EXISTS tier_expires_at,
  DROP COLUMN IF EXISTS tier;
COMMIT;

-- 006_create_subscriptions_table.down.sql
BEGIN;
DROP TABLE IF EXISTS provider_webhook_events;
DROP TABLE IF EXISTS subscriptions;
COMMIT;
```

### 4.4 Type definitions (TypeScript)

```typescript
// backend/src/types/tier.ts
export type Tier = 'open' | 'solo' | 'advanced' | 'enterprise';

export type SubscriptionStatus = 'trialing' | 'active' | 'past_due' | 'canceled' | 'expired';

  status: SubscriptionStatus;
  current_period_start?: Date;

  founder_seat_id?: string;
  cents_per_period: number;
  trial_started_at?: Date;
  trial_ends_at?: Date;
  created_at: Date;
  updated_at: Date;
}

export interface ProfileTier {
  tier: Tier;
  tier_expires_at?: Date;

```

## 6. BDD scenarios

```gherkin
Feature: Tier schema substrate exists

Scenario: Existing user defaults to Open tier post-migration
  Given a profile created before migration M1
  When migration M1 runs
  Then the profile.tier is "open"
  And profile.tier_expires_at is NULL
  And profile.pdf_sends_this_month is 0

Scenario: Subscription unique constraint
  Given a subscriptions row with provider="stripe", provider_subscription_id="sub_123"
  When another row is INSERTed with the same pair
  Then the INSERT fails with UNIQUE violation

Scenario: Webhook idempotency table prevents reprocess
  Given a Stripe event "evt_123" already inserted
  When a duplicate webhook with same event id arrives
  Then the row exists; the handler skips re-processing

Scenario: Migrations are reversible
  Given M1 + M2 applied
  When M1.down + M2.down run
  Then the schema returns to pre-migration state
  And no data corruption
```

## 7. Edge cases

| Case | Behavior |
|---|---|
| Concurrent migrations from multiple boot instances | Use advisory lock (`SELECT pg_advisory_xact_lock(0xMIGRATIONS_LOCK)`) — Hetzner deploy is single-instance for v1, but defensive |
| Profile deleted while subscription exists | `ON DELETE CASCADE` removes subscriptions too |
| Founder seat reference in subscriptions before founder_seats table exists | `founder_seat_id UUID` with no FK constraint at this PRD; FK added in F5.1 |
| Tier check constraint hit by typo | Fail-fast at INSERT/UPDATE; loud test failure |
