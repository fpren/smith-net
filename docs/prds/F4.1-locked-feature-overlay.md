# F4.1 — LockedFeatureOverlay component + 4 content variants

| Field | Value |
|---|---|
| Pitch | 4 — Tier-gate UI |
| Cycle | 3 |
| Appetite | 4 days |
| Owner | Android |
| Dependencies | F2.2 (entitlements), F5.1 (founder seats), F5.2 (telemetry), F6.1 (403 contract) |
| Closes blocker | B6 (partial — overlay component itself) |

---

## 1. Problem

The 4 lock-overlay variants (N2/N3 PLAN, N4 active-job-cap, N5 PDF-cap, N10 SmithAI, N11 Crew) all need the same Composable shell — only content differs. Without this, every gate-hit handler would reinvent the wheel.

## 2. Goal

A single `LockedFeatureOverlay` Composable per `WIREFRAME-SPEC §2`, taking content variants as parameters, rendering with `ConsoleTheme` tokens, calling tier-resolver / founder-seats / telemetry services, supporting all 11 states from `STATE-SPEC §N2`.

## 3. Non-goals

- The trigger sites (those are F4.6 wiring)
- The TierPricingScreen the CTA navigates to (F4.3)
- The TrialBanner that appears after CTA tap (F4.2)

## 4. Design

```kotlin
// android/app/src/main/java/com/guildofsmiths/trademesh/ui/components/LockedFeatureOverlay.kt
package com.guildofsmiths.trademesh.ui.components

import androidx.compose.animation.Crossfade
import androidx.compose.animation.core.tween
import androidx.compose.foundation.background
import androidx.compose.foundation.clickable
import androidx.compose.foundation.layout.*
import androidx.compose.material3.Text
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.alpha
import androidx.compose.ui.unit.dp
import com.guildofsmiths.trademesh.data.EntitlementsRepository
import com.guildofsmiths.trademesh.data.FounderBonusId
import com.guildofsmiths.trademesh.data.Tier
import com.guildofsmiths.trademesh.service.TelemetryService
import com.guildofsmiths.trademesh.service.TrialService
import com.guildofsmiths.trademesh.ui.ConsoleTheme

enum class LockVariant { PLAN_PREVIEW, PLAN_COMPILE, ACTIVE_JOB_CAP, PDF_CAP, AI_TAB, CREW_INVITE }

@Composable
fun LockedFeatureOverlay(
    variant: LockVariant,
    triggerEvent: String,
    targetTier: Tier,
    primaryCtaLabel: String,
    founderBonusId: FounderBonusId? = null,
    backgroundContent: @Composable () -> Unit,
    onConverted: () -> Unit,
    onDismiss: () -> Unit,
) {
    val content = remember(variant) { lockContentFor(variant) }
    val founderSeats by EntitlementsRepository.entitlements.collectAsState()
    var ctaInFlight by remember { mutableStateOf(false) }
    var isOnline by remember { mutableStateOf(true) }

    LaunchedEffect(Unit) {
        TelemetryService.emit(triggerEvent)
        TelemetryService.emit("tier_upgrade.cta_shown", mapOf("target_tier" to targetTier.name))
    }

    Crossfade(targetState = true, animationSpec = tween(200)) { _ ->
        Box(Modifier.fillMaxSize()) {
            // Bottom 40% — dimmed preview
            Box(
                Modifier
                    .fillMaxWidth()
                    .fillMaxHeight(0.6f)
                    .align(Alignment.BottomCenter)
                    .alpha(0.4f)
            ) {
                backgroundContent()
            }

            // Top card
            Column(
                Modifier
                    .fillMaxWidth()
                    .background(ConsoleTheme.surface)
                    .padding(14.dp)
            ) {
                Text(content.title, style = ConsoleTheme.captionBold, color = ConsoleTheme.primary)
                Spacer(Modifier.height(10.dp))
                Text(content.body, style = ConsoleTheme.body, color = ConsoleTheme.textPrimary)
                Spacer(Modifier.height(14.dp))
                Text(content.tierLabel, style = ConsoleTheme.bodyBold)

                if (founderBonusId != null) {
                    Spacer(Modifier.height(8.dp))
                    FounderSeatsCounter(bonusId = founderBonusId)
                }

                Spacer(Modifier.height(14.dp))
                PrimaryCta(
                    label = if (!isOnline) "NO CONNECTION — OFFLINE"
                            else if (ctaInFlight) "STARTING TRIAL..."
                            else primaryCtaLabel,
                    enabled = isOnline && !ctaInFlight,
                    onClick = {
                        ctaInFlight = true
                        TelemetryService.emit("tier_upgrade.cta_clicked", mapOf("target_tier" to targetTier.name))
                        TrialService.startTrial(targetTier, founderBonusId) { result ->
                            ctaInFlight = false
                            when (result) {
                                is TrialResult.Success -> onConverted()
                                is TrialResult.Failure -> showToast("Couldn't start trial. Try again.")
                            }
                        }
                    }
                )
                Spacer(Modifier.height(12.dp))
                Text(
                    "Maybe later",
                    style = ConsoleTheme.caption.copy(color = ConsoleTheme.textMuted),
                    modifier = Modifier
                        .align(Alignment.CenterHorizontally)
                        .clickable {
                            TelemetryService.emit("tier_upgrade.cta_dismissed", mapOf("gate" to triggerEvent))
                            onDismiss()
                        }
                )
            }

            // Background tap (dimmed area) → dismiss
            Box(
                Modifier
                    .fillMaxWidth()
                    .fillMaxHeight(0.6f)
                    .align(Alignment.BottomCenter)
                    .clickable { onDismiss() }
            )
        }
    }
}

private fun lockContentFor(variant: LockVariant): LockContent = when (variant) {
    LockVariant.PLAN_PREVIEW, LockVariant.PLAN_COMPILE -> LockContent(
        "PLAN COMPILER",
        "Your plan, compiled. Runs the same way every time.",
        "SOLO · \$2.99/MO"
    )
    LockVariant.ACTIVE_JOB_CAP -> LockContent(
        "ONE ACTIVE JOB AT A TIME",
        "Smith Net Open caps at 1. Close your active job to start another, or unlock unlimited with Solo.",
        "SOLO · \$2.99/MO"
    )
    LockVariant.PDF_CAP -> LockContent(
        "5 SENDS PER MONTH",
        "You've sent 5 PDFs this month on Open. Unlimited with Solo.",
        "SOLO · \$2.99/MO"
    )
    LockVariant.AI_TAB -> LockContent(
        "SMITHAI",
        "On-device. No cloud. Watches your jobs and helps without ever sending data anywhere.",
        "ADVANCED · \$9.99/MO"
    )
    LockVariant.CREW_INVITE -> LockContent(
        "CREW MODE",
        "Bring your crew on the same plan. \$50/mo for the whole team — not per seat.",
        "ENTERPRISE · \$50/MO"
    )
}

private data class LockContent(val title: String, val body: String, val tierLabel: String)
```

`PrimaryCta` is a small custom Composable (filled `primary` bg, white text, 14dp padding, RoundedCornerShape(6dp), disabled state per DESIGN-SYSTEM §9).

  And LockedFeatureOverlay PLAN_PREVIEW is shown

  And while in flight, button shows "STARTING TRIAL..."
  And on success, onConverted is invoked

  And tap does nothing

## 7. Edge cases

| Case | Behavior |
|---|---|
| Reduced motion enabled | Crossfade duration → 0 (instant) |
| Founder counter API stale | FounderSeatsCounter renders last-known with 50% alpha dot (per F4.2 spec) |
| Trial start request hangs > 5s | Client-side timeout; CTA re-enables; Toast warns |
| User backgrounds app mid-overlay | onDismiss not called; overlay still open on resume; founder counter refreshes |
