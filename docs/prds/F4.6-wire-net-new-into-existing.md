# F4.6 — Wire net-new UI into existing screens

| Field | Value |
|---|---|
| Pitch | 4 — Tier-gate UI |
| Cycle | 3 |
| Appetite | 3 days |
| Owner | Android |
| Dependencies | F4.1, F4.2, F4.3, F4.4, F4.5 |

## 1. Problem

The 7 net-new components from F4.1-F4.5 exist in isolation. They need to fire from the right places in the existing codebase without restyling existing screens.

## 2. Goal

7 surgical edits to existing screens to invoke net-new components per `WIREFRAME-SPEC §11`. No restyling of existing UI.

```kotlin
viewModel.createJob(...)

                onConverted = { viewModel.retrySave() },
                onDismiss = { /* form state preserved */ }
            )
        } else {
            showError(err)
        }
    }
```

### 3.7 C1 DashboardScreen.kt — UPGRADE quick-action tile

```kotlin
fun getQuickActions(role: Role, tier: Tier, ...): List<QuickAction> {
    val base = baseQuickActions(role, ...)
    val upgradeTile = when (tier) {
        Tier.OPEN -> QuickAction("UPGRADE", { nav.navigate(Route.TierPricing) })
        Tier.SOLO -> QuickAction("ADD SMITHAI", { nav.navigate(Route.TierPricing(scrollTo = Tier.ADVANCED)) })
        Tier.ADVANCED -> QuickAction("ADD CREW", { nav.navigate(Route.TierPricing(scrollTo = Tier.ENTERPRISE)) })
        Tier.ENTERPRISE -> null
    }
    return base + listOfNotNull(upgradeTile)
}
```

## 4. Acceptance criteria

| AC | Description |
|---|---|
| AC-1 | TrialBanner appears at top of every screen during trial; sits below status bar |
| AC-2 | OnboardingScreen → WelcomeToOpenScreen on completion |
| AC-3 | Q2 Settings has new SUBSCRIPTION section above PROFILE |
| AC-4 | Q2 AI ASSISTANT shows EntitlementLock when tier < ADVANCED |
| AC-5 | D3 NewJobFlow Save → 403 → N4 overlay opens; form state preserved |
| AC-6 | H1 InvoiceScreen send dialog footer shows PdfSendCounterFooter for Open tier |
| AC-7 | H1 Send → 403 → N5 overlay opens |
| AC-8 | E1 PlanScreen for Free user shows N3 overlay over sample plan content |
| AC-9 | C1 Dashboard quick-action tile labeled per current tier |
| AC-10 | Colleague invite for Solo/Advanced fires N11 overlay; for Enterprise opens existing flow |
| AC-11 | None of these wirings restyle the existing screens (no visual diff outside the inserted/conditional regions) |
| AC-12 | All wirings handle 403 tier_gate_exceeded by parsing `gate_id` and selecting correct LockVariant |
