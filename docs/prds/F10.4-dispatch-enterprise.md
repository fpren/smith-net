# F10.4 — DispatchScreen Enterprise-tier surfacing

| Field | Value |
|---|---|
| Pitch | 10 — Crew + dispatch |

---

## 1. Problem

`O1 DispatchScreen.kt` exists today (role-gated to foreman+/lead/enterprise/admin) but doesn't surface tier gating, doesn't visually expose crew assignment, and doesn't drag-drop jobs to crew members per the existing spec hint.

## 2. Goal

After this PRD: Enterprise tier + foreman+ role users get a working DispatchScreen showing all org jobs in a grid with crew assignment via drag-drop. Tier OR role missing → existing role-hide behavior.

## 3. Non-goals

- Real-time collaborative dispatch (crew sees dispatch but doesn't dispatch each other)
- Auto-assignment based on skill / availability
- Calendar integration
- Notifications to assigned crew (basic FCM only)

## 4. Design

### 4.1 Schema additions

```sql
-- 019_create_job_assignments_table.sql
CREATE TABLE IF NOT EXISTS job_assignments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  job_id UUID NOT NULL REFERENCES jobs(id) ON DELETE CASCADE,
  profile_id TEXT NOT NULL REFERENCES profiles(id) ON DELETE CASCADE,
  assigned_by TEXT NOT NULL REFERENCES profiles(id),
  assigned_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  removed_at TIMESTAMPTZ,
  UNIQUE (job_id, profile_id) WHERE removed_at IS NULL
);

CREATE INDEX idx_job_assignments_job ON job_assignments(job_id) WHERE removed_at IS NULL;
CREATE INDEX idx_job_assignments_profile ON job_assignments(profile_id) WHERE removed_at IS NULL;
```

(Replaces `jobs.assigned_to UUID[]` legacy — but legacy field stays for read compat; app-level migration syncs.)

### 4.3 Android DispatchScreen UI

Existing `O1 DispatchScreen.kt` enhanced:

```kotlin
@Composable
fun DispatchScreen(onBack: () -> Unit) {
    val ent by EntitlementsRepository.entitlements.collectAsState()
    val role = remember { RoleContext.role }

    // Tier + role gating
    if (ent?.caps?.crew != true) {
        // Should never reach if quick-action tile is hidden, but defense-in-depth
        LockedFeatureOverlay(
            variant = LockVariant.CREW_INVITE,
            triggerEvent = "gate_hit.crew_invite",
            targetTier = Tier.ENTERPRISE,
            primaryCtaLabel = "START 14-DAY ENTERPRISE TRIAL",
            backgroundContent = { DispatchPreviewSample() },
            onConverted = { /* refresh */ },
            onDismiss = onBack
        )
        return
    }

    val state by viewModel.dispatchState.collectAsState()
    Column(Modifier.fillMaxSize().background(ConsoleTheme.background)) {
        StandardHeader("DISPATCH", onBack)
        ConsoleSeparator()

        // Two-column: jobs (left), crew (right)
        Row(Modifier.fillMaxSize()) {
            JobsColumn(
                jobs = state.unassignedJobs,
                modifier = Modifier.weight(1f).fillMaxHeight(),
                onJobDrag = { jobId -> viewModel.startDrag(jobId) }
            )
            CrewColumn(
                members = state.members,
                assignments = state.assignments,
                modifier = Modifier.weight(1f).fillMaxHeight(),
                onJobDrop = { memberId -> viewModel.assignDraggedJobTo(memberId) }
            )
        }
    }
}

@Composable
private fun JobsColumn(jobs: List<Job>, ..., onJobDrag: (String) -> Unit) {
    Column(Modifier.padding(16.dp).verticalScroll(rememberScrollState())) {
        Text("UNASSIGNED JOBS", style = ConsoleTheme.captionBold)
        Spacer(Modifier.height(10.dp))
        jobs.forEach { job ->
            JobCardDraggable(job, onDragStart = { onJobDrag(job.id) })
            Spacer(Modifier.height(8.dp))
        }
    }
}

@Composable
private fun CrewColumn(members: List<OrgMember>, assignments: List<JobAssignment>, ..., onJobDrop: (String) -> Unit) {
    Column(Modifier.padding(16.dp)) {
        Text("CREW", style = ConsoleTheme.captionBold)
        Spacer(Modifier.height(10.dp))
        members.forEach { member ->
            CrewMemberDropTarget(
                member = member,
                assignedJobs = assignments.filter { it.profileId == member.id }
                    .map { state.jobs.find { j -> j.id == it.jobId } }.filterNotNull(),
                onDrop = { onJobDrop(member.id) }
            )
            Spacer(Modifier.height(8.dp))
        }
    }
}
```

(Drag-drop via `Modifier.pointerInput` + remembered drag state — standard Compose pattern, no new lib.)

### 4.4 Quick-action gating

`getQuickActions(role, tier, ...)` — DISPATCH tile shown only when `tier=enterprise` AND `role in (foreman, lead, owner, admin)`. For Enterprise + Solo role: tile hidden. For non-Enterprise foreman: tile hidden (this is also a tier feature, not just role).

## 5. Acceptance criteria

| AC | Description |
|---|---|
| AC-1 | job_assignments table created |
| AC-2 | POST /api/jobs/:id/assign requires Enterprise tier + foreman+ role |
| AC-3 | Assignment fires FCM push to assigned crew member |
| AC-4 | GET /api/orgs/me/dispatch returns jobs + members + assignments |

| AC-10 | Unassign endpoint soft-deletes (removed_at) |

## 6. BDD scenarios

```gherkin
Scenario: Foreman assigns job to crew

  And an unassigned job in org X
  When they drag the job onto crew member jane in DispatchScreen
  Then POST /api/jobs/:id/assign with profile_id=jane.id is called
  And job_assignments row created
  And jane receives FCM push

Scenario: Solo user opens DispatchScreen quick-action — tile not visible
  Given a Solo foreman
  When they view C1 Dashboard quick-actions
  Then no DISPATCH tile is rendered

Scenario: Enterprise expires; assignments preserved but read-only
  Given an org whose subscription expired
  And existing job_assignments rows
  When a member opens DispatchScreen via direct nav
  Then LockedFeatureOverlay (CREW_INVITE variant) appears
  And assignments remain in DB

Scenario: Member cannot assign jobs
  Given Enterprise 'member' role (not foreman+)
  When they POST /api/jobs/:id/assign
  Then 403 requires_dispatcher_role
```

## 7. Edge cases

| Case | Behavior |
|---|---|
| Drag started but app backgrounded | Drag state cleared; user retries |
| Assignment to user no longer in org | Server validates org match; rejects 400 |
| Multiple foremen assigning to same member same job concurrently | UNIQUE constraint deduplicates; second insert no-ops |
| Member unassigned mid-action | Assignment removed; FCM not sent for removal (silent) |
