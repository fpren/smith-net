# F9.1 — Advanced invoice template

| Field | Value |
|---|---|
| Pitch | 9 — Advanced + Enterprise templates |
| Cycle | 4 |
| Appetite | 3 days |
| Owner | backend + Android |
| Dependencies | F2.2, F6.1, F8.1 |
| Closes blocker | B9 (Advanced part) |

---

## 1. Problem

Standard invoice template is the only one shipping. Advanced tier ($9.99/mo) needs visibly richer template to justify the upgrade. Per `pricing-config.json`: Advanced = "Solo + Advanced invoice template + SmithAI."

## 2. Goal

After this PRD: Advanced+ users can select an Advanced template that includes line-item richness (per-item notes, photos, terms, payment-status timeline). Server enforces tier match.

## 3. Non-goals

- Custom-template editor (post-launch)
- WYSIWYG drag-drop builder (no)
- Logo upload (Solo+ already removes Smith Net branding; logo support is post-launch)

## 4. Design

### 4.1 Migration M5 — `add_template_to_invoices.sql`

```sql
-- 012_add_template_to_invoices.sql
ALTER TABLE invoices
  ADD COLUMN IF NOT EXISTS template TEXT NOT NULL DEFAULT 'standard'
    CHECK (template IN ('standard', 'advanced', 'enterprise'));
ALTER TABLE invoice_links
  ADD COLUMN IF NOT EXISTS template TEXT NOT NULL DEFAULT 'standard'
    CHECK (template IN ('standard', 'advanced', 'enterprise'));
```

```sql

ALTER TABLE invoices
```

### 4.4 Server tier-match enforcement at send time

```typescript
// In POST /api/invoices/:id/send (extending F6.1 + F8.1):
const { rows: invRows } = await pg.query(`SELECT template FROM invoices WHERE id=$1`, [invoiceId]);
const template = invRows[0].template;

// Tier check per template
if (template === 'advanced' && TIER_RANK[ent.tier] < TIER_RANK['advanced']) {
  return res.status(403).json({
    error: 'Advanced template requires Advanced tier',
    code: 'tier_gate_exceeded',
    gate_id: 'advanced_template',
    current_tier: ent.tier,
    details: { target_tier: 'advanced' },
  });
}
if (template === 'enterprise' && TIER_RANK[ent.tier] < TIER_RANK['enterprise']) { /* same */ }

// Render correct template
const pdfBuffer = await renderInvoicePdf(invoiceId, { template, isOpenTier: ent.tier === 'open' });
```

### 4.5 Android H1 InvoiceScreen template selector

```kotlin
@Composable
fun TemplateSelector(currentTemplate: String, onSelect: (String) -> Unit) {
    val ent by EntitlementsRepository.entitlements.collectAsState()
    Column {
        Text("TEMPLATE", style = ConsoleTheme.captionBold)
        Spacer(Modifier.height(10.dp))
        TemplateRow("Standard", "standard", currentTemplate, onSelect, locked = false)
        TemplateRow("Advanced", "advanced", currentTemplate, onSelect, locked = !ent?.caps?.advancedTemplate.orFalse())
        TemplateRow("Enterprise", "enterprise", currentTemplate, onSelect, locked = !ent?.caps?.enterpriseTemplate.orFalse())
    }
}

@Composable
private fun TemplateRow(label: String, value: String, current: String, onSelect: (String) -> Unit, locked: Boolean) {
    Row(
        Modifier.fillMaxWidth().background(ConsoleTheme.surface)
            .clickable(enabled = !locked) {
                if (locked) showLockedFeatureOverlay(...)
                else onSelect(value)
            }
            .padding(14.dp),
        verticalAlignment = Alignment.CenterVertically,
        horizontalArrangement = Arrangement.SpaceBetween
    ) {
        Row(verticalAlignment = Alignment.CenterVertically) {
            if (locked) {
                Box(Modifier.size(8.dp).clip(CircleShape).background(ConsoleTheme.statusGrey))
                Spacer(Modifier.width(8.dp))
            }
            Text(label, style = if (current == value) ConsoleTheme.bodyBold else ConsoleTheme.body,
                 color = if (locked) ConsoleTheme.textMuted else ConsoleTheme.textPrimary)
        }
        if (current == value) Text("●", color = ConsoleTheme.primary)
        else if (locked) Text(">", color = ConsoleTheme.textMuted)
    }
}
```

## 7. Edge cases

| Case | Behavior |
|---|---|
| User downgrades from Adv→Solo with Advanced-template draft | Template field unchanged in DB; send-time tier check rejects; user must re-pick Standard |
| Photos referenced in line_items but URL no longer accessible | Render renders broken image; not blocking |
| Terms text contains HTML | Server escapes via Handlebars (default) |
