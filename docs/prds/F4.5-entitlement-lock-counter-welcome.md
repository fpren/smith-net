## 2. Design

### 2.1 EntitlementLock

```kotlin
// android/.../ui/components/EntitlementLock.kt
@Composable
fun EntitlementLock(
    sectionTitle: String,
    bodyText: String,
    targetTier: Tier,
    trialDuration: Int,
    onClick: () -> Unit,
) {
    Column {
        Text(sectionTitle, style = ConsoleTheme.captionBold)
        Spacer(Modifier.height(10.dp))

        Row(
            Modifier
                .fillMaxWidth()
                .background(ConsoleTheme.surface)
                .clickable { onClick() }
                .padding(14.dp),
            verticalAlignment = Alignment.CenterVertically,
            horizontalArrangement = Arrangement.SpaceBetween
        ) {
            Column(Modifier.weight(1f)) {
                Row(verticalAlignment = Alignment.CenterVertically) {
                    Box(Modifier.size(8.dp).clip(CircleShape).background(ConsoleTheme.statusGrey))
                    Spacer(Modifier.width(8.dp))
                    Text("Locked — ${displayName(targetTier)} tier", style = ConsoleTheme.bodyBold)
                }
                Spacer(Modifier.height(4.dp))
                Text(bodyText, style = ConsoleTheme.caption.copy(color = ConsoleTheme.textMuted))
            }
            Text(">", style = ConsoleTheme.body, color = ConsoleTheme.textMuted)
        }

        Spacer(Modifier.height(8.dp))
        Text(
            "[ Try ${displayName(targetTier)} free $trialDuration days — no CC ]",
            style = ConsoleTheme.caption,
            color = ConsoleTheme.primary,
            modifier = Modifier.clickable { onClick() }
        )
    }
}
```

### 2.2 PdfSendCounterFooter

```kotlin
// android/.../ui/components/PdfSendCounterFooter.kt
@Composable
fun PdfSendCounterFooter(sendsUsedThisMonth: Int, cap: Int = 5) {
    val (text, color) = when {
        sendsUsedThisMonth == 0 -> "0 of $cap free sends used this month" to ConsoleTheme.textMuted
        sendsUsedThisMonth in 1..3 -> "$sendsUsedThisMonth of $cap free sends used this month" to ConsoleTheme.textMuted
        sendsUsedThisMonth == 4 -> "4 of $cap free sends used this month — 1 left" to ConsoleTheme.textPrimary
        else -> "$sendsUsedThisMonth of $cap free sends used this month — full" to ConsoleTheme.textPrimary
    }
    Column {
        ConsoleSeparator()
        Spacer(Modifier.height(12.dp))
        Text(text, style = ConsoleTheme.caption, color = color)
    }
}
```

Hidden when tier ≥ Solo — caller checks `entitlements.caps.pdfSendsPerMonth != 'unlimited'`.

## 3. Acceptance criteria

| AC | Description |
|---|---|
| AC-1 | EntitlementLock renders only when tier < targetTier (caller's responsibility) |
| AC-2 | EntitlementLock shows "● Locked — Advanced tier" with gray dot |
| AC-3 | EntitlementLock tap → onClick (parent opens overlay) |
| AC-4 | EntitlementLock text-link below row uses primary blue |
| AC-5 | PdfSendCounterFooter color steps: 0-3 muted, 4 emphasized, 5+ emphasized |
| AC-6 | PdfSendCounterFooter hidden when paid tier (caller-gated) |
| AC-7 | WelcomeToOpenScreen has no back arrow (one-way after onboarding) |
| AC-8 | WelcomeToOpenScreen renders FounderSeatsCounter at bottom of Solo section |
| AC-9 | All 3 components use ConsoleTheme tokens only |
| AC-10 | TalkBack flows: section title → status row → caption → text-link CTA |

## 4. BDD scenarios

```gherkin
Scenario: EntitlementLock for Solo user opening AI Settings
  Given a Solo user
  When Q2 SettingsScreen renders the AI ASSISTANT section
  Then EntitlementLock is rendered with sectionTitle="AI ASSISTANT"
  And the row shows "● Locked — Advanced tier"
  And the text-link below shows "[ Try Advanced free 30 days — no CC ]"
  When the user taps the row
  Then the parent invokes the AI lock overlay (per F4.6 wiring)

Scenario: PDF counter at 4 sends shows emphasized text
  Given a Free user with pdf_sends_this_month = 4
  When PdfSendCounterFooter renders
  Then the text reads "4 of 5 free sends used this month — 1 left"
  And the color is textPrimary (not muted)

Scenario: WelcomeToOpenScreen shown after onboarding
  Given a new user just completed onboarding
  When MainActivity routes to WelcomeToOpenScreen
  Then there's no back arrow
  And both CTAs visible
  When user taps "START SOLO TRIAL — NO CC"
  Then onStartSoloTrial fires (parent calls TrialService)
  When user taps "Stay on Open"
  Then onStayOnOpen fires (parent navigates to C1 Dashboard)
```
