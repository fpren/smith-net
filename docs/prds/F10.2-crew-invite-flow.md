# F10.2 — Crew invite + accept flow

| Field | Value |
|---|---|
| Pitch | 10 — Crew + dispatch |
| Cycle | 5 |
| Appetite | 4 days |
| Owner | backend + Android |
| Dependencies | F10.1 (org + members exist), F1.4 (email service) |

---

## 1. Problem

Enterprise owner needs to invite colleagues via email; invitee needs to accept (whether they have an existing Smith Net account or not). N11 lock fires for non-Enterprise; this PRD handles the post-unlock real flow.

## 2. Goal

After this PRD: owner taps "+ Invite colleague" → enters email → invitee receives email → taps link → either signs up + auto-joins, or accepts via existing-account flow → becomes org member.

## 3. Non-goals

- Bulk CSV import
- Per-member custom permissions (use existing 6 roles)
- Removing colleagues immediately deletes their data (soft-only)

## 4. Design

### 4.1 Schema

```sql
-- 017_create_crew_invites_table.sql
CREATE TABLE IF NOT EXISTS crew_invites (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  org_id UUID NOT NULL REFERENCES organizations(id) ON DELETE CASCADE,
  invited_by TEXT NOT NULL REFERENCES profiles(id),
  invited_email TEXT NOT NULL,
  invited_role TEXT NOT NULL DEFAULT 'member' CHECK (invited_role IN ('member','lead','foreman')),
  token TEXT UNIQUE NOT NULL,
  expires_at TIMESTAMPTZ NOT NULL,
  status TEXT NOT NULL DEFAULT 'pending'
    CHECK (status IN ('pending','accepted','revoked','expired')),
  accepted_by_profile_id TEXT REFERENCES profiles(id),
  accepted_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_crew_invites_token ON crew_invites(token) WHERE status = 'pending';
CREATE INDEX idx_crew_invites_org ON crew_invites(org_id);
```

### 4.2 Endpoint: POST /api/orgs/me/invite

```typescript
const InviteBody = z.object({
  email: z.string().email().toLowerCase(),
  role: z.enum(['member','lead','foreman']).default('member'),
}).strict();

apiRouter.post('/orgs/me/invite', validateBody(InviteBody), async (req: AuthenticatedRequest, res) => {
  const profileId = req.user!.id;
  const ent = await resolveTier(profileId);

  // Tier check
  if (!ent.caps.crew) {
    return res.status(403).json({
      error: 'Crew requires Enterprise tier',
      code: 'tier_gate_exceeded',
      gate_id: 'crew_invite',
      current_tier: ent.tier,
      details: { target_tier: 'enterprise' },
    });
  }

  // Owner check
  const { rows: orgRows } = await pg.query(`
    SELECT o.id FROM organizations o
      JOIN org_members om ON om.org_id = o.id
     WHERE om.profile_id = $1 AND om.role = 'owner' AND o.subscription_id IS NOT NULL
  `, [profileId]);
  if (orgRows.length === 0) return res.status(403).json({ error: 'not_owner_or_inactive_subscription' });
  const orgId = orgRows[0].id;

  const { email, role } = req.body;
  const token = crypto.randomBytes(24).toString('hex');
  const expiresAt = new Date(Date.now() + 7 * 86_400_000); // 7 days

  await pg.query(`
    INSERT INTO crew_invites (org_id, invited_by, invited_email, invited_role, token, expires_at)
    VALUES ($1, $2, $3, $4, $5, $6)
  `, [orgId, profileId, email, role, token, expiresAt]);

  // Send email
  await emailService.send({
    to: email,
    subject: `${(await getProfile(profileId)).display_name} invited you to Smith Net`,
    body: `Tap to join their crew on Smith Net:

https://app.smithnet.app/crew/accept?token=${token}

This link expires in 7 days. If you don't have a Smith Net account, you'll be prompted to create one.

— Smith Net (smithnet.app)`,
  });

  await emit('crew.invite_sent', profileId, ent.tier, { invited_email: maskEmail(email), role });

  res.status(201).json({ invite_id: token, expires_at: expiresAt });
});
```

### 4.3 Endpoint: GET /api/crew/accept?token=:token

Public (no auth required for invitee, since they may not have an account):

```typescript
app.get('/crew/accept', async (req, res) => {
  const { token } = req.query;
  const { rows } = await pg.query(`
    SELECT ci.*, o.name AS org_name, p.display_name AS inviter_name
      FROM crew_invites ci
      JOIN organizations o ON o.id = ci.org_id
      JOIN profiles p ON p.id = ci.invited_by
     WHERE ci.token = $1 AND ci.status = 'pending' AND ci.expires_at > NOW()
  `, [token]);
  if (rows.length === 0) {
    return res.status(404).render('crew-accept-failed.html', { reason: 'expired_or_invalid' });
  }
  // Render accept page (server-side HTML)
  res.render('crew-accept.html', {
    org_name: rows[0].org_name,
    inviter_name: rows[0].inviter_name,
    invited_email: rows[0].invited_email,
    token,
  });
});
```

### 4.4 Accept actions

```typescript
// POST /api/crew/accept (after user signs up OR logs in via the accept page)
const AcceptBody = z.object({ token: z.string() }).strict();

apiRouter.post('/crew/accept', validateBody(AcceptBody), async (req: AuthenticatedRequest, res) => {
  const { token } = req.body;
  const profileId = req.user!.id;

  const { rows } = await pg.query(`
    SELECT * FROM crew_invites WHERE token = $1 AND status = 'pending' AND expires_at > NOW()
  `, [token]);
  if (rows.length === 0) return res.status(404).json({ error: 'expired_or_invalid' });
  const invite = rows[0];

  // Email match: invitee's account email must match invited_email
  const profile = await getProfile(profileId);
  if (profile.email.toLowerCase() !== invite.invited_email.toLowerCase()) {
    return res.status(403).json({ error: 'email_mismatch', invited_email: invite.invited_email });
  }

  // Org subscription must still be active
  const { rows: orgRows } = await pg.query(`
    SELECT subscription_id FROM organizations WHERE id = $1
  `, [invite.org_id]);
  if (!orgRows[0].subscription_id) {
    return res.status(400).json({ error: 'org_subscription_expired' });
  }

  // Add member
  await pg.query(`
    INSERT INTO org_members (org_id, profile_id, role) VALUES ($1, $2, $3)
    ON CONFLICT (org_id, profile_id) DO UPDATE SET removed_at = NULL, role = EXCLUDED.role
  `, [invite.org_id, profileId, invite.invited_role]);

  // Mark invite accepted
  await pg.query(`
    UPDATE crew_invites SET status='accepted', accepted_by_profile_id=$2, accepted_at=NOW()
     WHERE id=$1
  `, [invite.id, profileId]);

  // Set primary org if not already set
  await pg.query(`UPDATE profiles SET org_id = $2 WHERE id = $1 AND org_id IS NULL`,
                 [profileId, invite.org_id]);

  await emit('crew.invite_accepted', profileId, 'enterprise', {});

  res.status(200).json({ org_id: invite.org_id, role: invite.invited_role });
});
```

### 4.5 Owner removes member

```typescript
// POST /api/orgs/me/remove-member { profile_id }
apiRouter.post('/orgs/me/remove-member', async (req: AuthenticatedRequest, res) => {
  // Verify caller is owner (per F10.1 pattern)
  // ...
  const { profile_id: targetId } = req.body;
  await pg.query(`
    UPDATE org_members SET removed_at = NOW() WHERE org_id = $1 AND profile_id = $2
  `, [orgId, targetId]);
  // Clear target's primary org
  await pg.query(`UPDATE profiles SET org_id = NULL WHERE id = $1 AND org_id = $2`, [targetId, orgId]);
  res.status(204).end();
});
```

## 5. Acceptance criteria

| AC | Description |
|---|---|
| AC-1 | Migration creates crew_invites table |
| AC-2 | POST /api/orgs/me/invite by Enterprise owner → invite row + email sent |
| AC-3 | POST by non-owner → 403 not_owner |
| AC-4 | POST by non-Enterprise → 403 tier_gate_exceeded crew_invite |
| AC-5 | Email contains valid link with token |
| AC-6 | Token expires after 7 days |
| AC-7 | GET /crew/accept?token=valid renders accept page |
| AC-8 | GET with expired token → 404 with reason 'expired_or_invalid' |
| AC-9 | POST /api/crew/accept by user with matching email → joins org, role applied |
| AC-10 | POST with non-matching email → 403 email_mismatch (returns invited_email so user knows) |
| AC-11 | Owner can remove member; soft-delete via removed_at; org_id cleared on profile |
| AC-12 | Re-invite of same email after removal → ON CONFLICT clears removed_at |
| AC-13 | Telemetry crew.invite_sent + crew.invite_accepted fire |

## 6. BDD scenarios

```gherkin
Scenario: Enterprise owner invites colleague
  Given Enterprise-tier user owning an org
  When POST /api/orgs/me/invite { email: "jane@example.com", role: "member" }
  Then crew_invites row created with status="pending"
  And email sent to jane@example.com with accept link
  And telemetry "crew.invite_sent" fires

Scenario: Non-Enterprise user attempts invite
  Given Solo-tier user
  When POST /api/orgs/me/invite
  Then 403 with code "tier_gate_exceeded", gate_id="crew_invite"

Scenario: Invitee accepts with matching email
  Given a pending invite for "jane@example.com"
  When jane (existing user with that email) POSTs /api/crew/accept
  Then she becomes an org_member with the invited role
  And invite status='accepted'
  And jane's profile.org_id is set
  And telemetry "crew.invite_accepted" fires

Scenario: Email mismatch rejected
  Given a pending invite for "jane@example.com"
  When bob@otherdomain.com POSTs /api/crew/accept with the token
  Then 403 email_mismatch
  And invite remains pending

Scenario: Expired invite rejected
  Given a crew_invite with expires_at in the past
  When invitee tries to accept
  Then 404 expired_or_invalid

Scenario: Owner removes member
  When owner POSTs /api/orgs/me/remove-member { profile_id: bobId }
  Then bob's org_members.removed_at is set
  And bob's profile.org_id is cleared
  And bob loses access to crew data on next request
```

## 7. Edge cases

| Case | Behavior |
|---|---|
| Invitee never created an account | Accept page redirects to /register?invite_token=...; on register, auto-call POST /api/crew/accept |
| Multiple pending invites for same email | Each must be accepted separately; but accept on any auto-revokes others (optional refinement) |
| Owner deletes own account | Org orphaned; admin must re-assign owner (out of scope; flag) |
| Subscription expires while invite pending | Accept blocks at "org_subscription_expired" error; invite expires naturally |
| Same user invited to two different orgs | profile.org_id holds primary; second org accessible via secondary query (not v1 UX) |
