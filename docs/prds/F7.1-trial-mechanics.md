## 1. Problem

Trial system doesn't exist. Need: 14-day Solo (no CC), 30-day Advanced (no CC), 14-day Enterprise (CC required). Plus cron-based expiry → downgrade with data preservation.

## 2. Goal

After this PRD: any user can start a trial; trials auto-downgrade at expiry; data preserved on downgrade; founder seats released on expiry.

## 3. Design

### 3.1 Endpoint POST /api/me/start-trial

```typescript
const StartTrialBody = z.object({
  targetTier: z.enum(['solo', 'advanced', 'enterprise']),
}).strict();

apiRouter.post('/me/start-trial', requireVerifiedEmail, validateBody(StartTrialBody),
  async (req: AuthenticatedRequest, res) => {
    const { targetTier } = req.body;
    const profileId = req.user!.id;

    // Validate: no prior trial of same tier
    const { rows: priorTrials } = await pg.query(
      `SELECT 1 FROM subscriptions
        WHERE profile_id = $1 AND tier = $2 AND trial_started_at IS NOT NULL
        LIMIT 1`,
      [profileId, targetTier]
    );
    if (priorTrials.length > 0) {
      return res.status(400).json({ error: 'Already used trial for this tier', code: 'trial_already_used' });
    }

    // Validate: current tier < target tier
    const ent = await resolveTier(profileId);
    if (TIER_RANK[ent.tier] >= TIER_RANK[targetTier]) {
      return res.status(400).json({ error: 'Already on or above this tier', code: 'tier_downgrade_via_trial' });
    }

    // Enterprise requires CC up front (per pricing-config.json design)
    if (targetTier === 'enterprise') {
      // Redirect to Stripe Checkout with trial_period_days=14
      // (Stripe handles trial-to-charge transition automatically)
      const session = await stripe.checkout.sessions.create({
        mode: 'subscription',
        customer_email: req.user!.email,
        client_reference_id: profileId,
        line_items: [{ price: process.env.STRIPE_PRICE_ENT_MONTHLY!, quantity: 1 }],
        subscription_data: { trial_period_days: 14, metadata: { profileId, targetTier } },
        success_url: `${PORTAL_URL}/subscription/success?session_id={CHECKOUT_SESSION_ID}`,
        cancel_url: `${PORTAL_URL}/subscription/canceled`,
      });
      return res.json({ requires_cc_checkout: true, checkout_url: session.url });
    }

    // Solo / Advanced: no-CC trial
    const durationDays = targetTier === 'solo' ? 14 : 30;
    const trialEndsAt = new Date(Date.now() + durationDays * 86_400_000);

    // Optionally reserve founder seat
    const founderBonus = founderBonusFor(targetTier);
    let founderSeatId: string | undefined;
    if (founderBonus) {
      const r = await reserveFounderSeat(founderBonus, profileId);
      if (r) founderSeatId = r.id;
    }

    // Insert trialing subscription
    const subId = uuidv4();
    await pg.query(`
      INSERT INTO subscriptions
        (id, profile_id, tier, cadence, provider, provider_subscription_id, status,
         current_period_start, current_period_end, trial_started_at, trial_ends_at,
         cents_per_period, founder_price_locked, founder_seat_id)
      VALUES ($1, $2, $3, 'monthly', 'manual', $4, 'trialing',
              NOW(), $5, NOW(), $5, $6, $7, $8)
    `, [subId, profileId, targetTier, `trial_${subId}`, trialEndsAt,
        targetTier === 'solo' ? 299 : 999, !!founderSeatId, founderSeatId]);

    // Update profile.tier + tier_expires_at
    await pg.query(
      `UPDATE profiles SET tier=$2, tier_expires_at=$3, trial_started_at=NOW(), trial_tier=$2
        WHERE id=$1`,
      [profileId, targetTier, trialEndsAt]
    );

    // Telemetry
    await emitTelemetry('tier_upgrade.trial_started', profileId, targetTier, {
      from_tier: ent.tier, to_tier: targetTier, founder_locked: !!founderSeatId,
    });

    // Re-issue tokens with new tier claim
    const newTokens = generateTokens({ ...req.user!, tier: targetTier });
    res.json({ ...newTokens, entitlements: await resolveTier(profileId) });
  }
);
```

### 3.2 Trial-expirer cron (also handles paid expirations per F3.3)

```typescript
// backend/src/jobs/trialExpirer.ts
export async function expireTrialsAndExpiredSubs() {
  // 1. Trials with no payment_method that have ended
  const { rows: expiringTrials } = await pg.query(`
    SELECT s.id, s.profile_id, s.tier, p.email, p.display_name
      FROM subscriptions s JOIN profiles p ON p.id = s.profile_id
     WHERE s.status = 'trialing' AND s.trial_ends_at <= NOW()
     LIMIT 200
  `);

  for (const trial of expiringTrials) {
    await pg.query(`UPDATE subscriptions SET status='expired' WHERE id=$1`, [trial.id]);

    // Determine downgrade target
    const downgradeTo = await deriveDowngradeTier(trial.profile_id, trial.tier);

    await pg.query(`
      UPDATE profiles SET tier=$2, tier_expires_at=NULL, trial_started_at=NULL, trial_tier=NULL
       WHERE id=$1
    `, [trial.profile_id, downgradeTo]);

    // Release founder seat if held
    const { rows: subRows } = await pg.query(
      `SELECT founder_seat_id FROM subscriptions WHERE id=$1`, [trial.id]);
    if (subRows[0]?.founder_seat_id) await releaseFounderSeat(subRows[0].founder_seat_id);

    // FCM push
    await sendPush(trial.profile_id, {
      title: `${displayName(trial.tier)} trial ended`,
      body: `You're back on ${displayName(downgradeTo)}. Reactivate any time.`,
    });

    // Audit + telemetry
    auditLog.log(AuditAction.USER_PROFILE_UPDATE, trial.profile_id, {
      reason: 'trial_expired', from_tier: trial.tier, to_tier: downgradeTo,
    });
    await emitTelemetry('tier_upgrade.trial_expired', trial.profile_id, downgradeTo, {
      from_tier: trial.tier,
    });

    console.info('[trial-expirer] downgraded', trial.profile_id, trial.tier, '->', downgradeTo);
  }

  // 2. Paid subscriptions whose period ended (canceled or past_due that didn't recover)
  const { rows: expiredPaid } = await pg.query(`
    SELECT s.id, s.profile_id, s.tier
      FROM subscriptions s
     WHERE s.status IN ('canceled', 'past_due')
       AND s.current_period_end <= NOW()
     LIMIT 200
  `);
  for (const sub of expiredPaid) {
    const downgradeTo = await deriveDowngradeTier(sub.profile_id, sub.tier);
    await pg.query(`UPDATE subscriptions SET status='expired' WHERE id=$1`, [sub.id]);
    await pg.query(`UPDATE profiles SET tier=$2 WHERE id=$1`, [sub.profile_id, downgradeTo]);
    await sendPush(sub.profile_id, {
      title: `Subscription ended`,
      body: `You're back on ${displayName(downgradeTo)}. Your data stays.`,
    });
    auditLog.log(AuditAction.USER_PROFILE_UPDATE, sub.profile_id, {
      reason: 'period_end', from_tier: sub.tier, to_tier: downgradeTo,
    });
    await emitTelemetry('tier_downgrade.canceled', sub.profile_id, downgradeTo, { from_tier: sub.tier });
  }
}

async function deriveDowngradeTier(profileId: string, fromTier: Tier): Promise<Tier> {
  // Find highest tier among other active paid subscriptions for this user
  const { rows } = await pg.query(`
    SELECT tier FROM subscriptions
     WHERE profile_id=$1 AND status='active' AND tier != $2
     ORDER BY CASE tier
       WHEN 'enterprise' THEN 4 WHEN 'advanced' THEN 3 WHEN 'solo' THEN 2 ELSE 1 END DESC
     LIMIT 1
  `, [profileId, fromTier]);
  return rows[0]?.tier ?? 'open';
}

cron.schedule('30 * * * *', expireTrialsAndExpiredSubs); // every hour at :30
```

## 4. Acceptance criteria

| AC | Description |
|---|---|
| AC-1 | POST /api/me/start-trial requires verified email + zod |
| AC-2 | Solo trial: no CC; immediate trial activation; profile.tier='solo' |
| AC-3 | Advanced trial: no CC; 30-day duration |
| AC-4 | Enterprise trial: returns Stripe Checkout URL with `trial_period_days=14`; user must complete checkout to activate |
| AC-5 | Same-tier trial reuse rejected with `trial_already_used` |
| AC-6 | Trial start reserves founder seat if available |
| AC-7 | New JWT with new tier claim returned in response |
| AC-8 | Hourly cron downgrades expired trials within 1h of trial_ends_at |
| AC-9 | Downgrade target = highest other paid tier OR 'open' |
| AC-10 | Founder seat released on trial expiry |
| AC-11 | FCM push sent on downgrade |
| AC-12 | Audit log entry on every downgrade |
| AC-13 | All user data preserved (no jobs/invoices/messages deleted) |
| AC-14 | Telemetry: trial_started, trial_expired, tier_downgrade.canceled fire correctly |

## 5. BDD scenarios

```gherkin
Scenario: Open user starts Solo no-CC trial
  Given verified Open user
  When POST /api/me/start-trial { targetTier: "solo" }
  Then a subscriptions row is inserted with status="trialing", trial_ends_at = NOW + 14 days
  And profiles.tier becomes "solo"
  And founder seat reserved if available
  And new JWT returned with tier="solo"
  And telemetry "tier_upgrade.trial_started" fires

Scenario: Same-tier trial cannot be re-used
  Given a user who already had a Solo trial in the past
  When POST /api/me/start-trial { targetTier: "solo" }
  Then 400 with code "trial_already_used"

Scenario: Enterprise trial requires CC checkout
  Given verified Advanced user
  When POST /api/me/start-trial { targetTier: "enterprise" }
  Then response includes requires_cc_checkout: true and checkout_url
  And no subscription row inserted yet
  When user completes Stripe Checkout
  Then F3.1 webhook handler creates subscription with status="trialing"

Scenario: Trial expiry downgrades
  Given a Solo trial with trial_ends_at in the past
  When trial-expirer cron runs
  Then subscription status becomes "expired"
  And profile.tier becomes "open" (no other paid subs)
  And founder seat released
  And FCM push sent
  And data preserved (jobs/invoices visible)

Scenario: Advanced trial expires for Solo paid user
  Given a Solo paid + Advanced trial
  When trial-expirer runs
  Then profile.tier becomes "solo" (highest other paid tier)
  And SmithAI model file kept on device (downgrade UX handled in F4.x)
```

## 6. Edge cases

| Case | Behavior |
|---|---|
| User adds CC during last hour of trial | Stripe handles transition; cron skips (no longer trialing) |
| Multiple devices, FCM only delivered to one | All devices auto-detect via JWT refresh on next API call |
| User mid-action when trial expires | Next API call returns 403 cap-exceeded; client overlays per F4.6 |
| Cron skipped run due to outage | Next run catches up (within 1h) |
| Trial start while founder seats exhausted | Trial still starts; just no founder lock |
